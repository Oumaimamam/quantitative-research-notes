# Quantitative Research Notes

**By Oumaima Mamoun**

Independent notes on quantitative finance, related to derivatives pricing, stochastic models, numerical methods, and quantitative computing.

This repository contains the source code for my research-notes website, built with [Quarto](https://quarto.org/).

## Publishing an article

Create a directory under `posts/` for each article:

```text
posts/
  article-name/
    index.qmd
    figures/
```

Add the article metadata and write the note in `index.qmd`:

```yaml
---
title: "Article title"
date: 2026-11-21
author: "Oumaima Mamoun"
categories: [Derivatives, Numerical methods]
description: "A concise summary for article listings."
---
```

The Research Notes archive and homepage are generated by Quarto listings. No listing HTML or CSS update is required. Remove `draft: true` only after the work has been independently reviewed and is safe to publish.

Run `quarto render` locally and verify `_site/index.html` and the rendered CSS references. Push to `main` to trigger the GitHub Pages workflow.

## Scope

- **Derivatives & hedging** — pricing, sensitivities, and hedging methods
- **Stochastic modelling** — processes and models used in quantitative finance
- **Numerical methods** — simulation, approximation, and calibration
- **Quantitative computing** — Python and C++ implementations
