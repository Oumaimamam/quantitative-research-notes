# Quant research blog starter

A minimal Quarto site with a GitHub Pages deployment workflow.

## Publish (one-time)

1. Create a public GitHub repository named `USERNAME.github.io` (replace USERNAME with your GitHub username).
2. Replace `USERNAME` in `_quarto.yml` with your GitHub username.
3. Upload all files **including the hidden `.github` folder** to the repository's `main` branch.
4. In repository **Settings → Pages → Build and deployment**, select **GitHub Actions**.
5. Check **Actions** for a successful `Publish Quarto site` run. Your site will be at `https://USERNAME.github.io`.

## Local preview (optional)

Install Quarto from https://quarto.org and run `quarto preview`.

## Publish an article

Copy `posts/first-note` to a new folder, update the metadata, remove `draft: true`, and write your independently verified article. Never publish confidential employer/client material.

The first-note article is a draft template and is not intended as finished research.
