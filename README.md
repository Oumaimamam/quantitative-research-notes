# Quantitative Research Notes

Independent notes on quantitative finance, related to derivatives pricing, stochastic models, numerical methods, and quantitative computing.

This repository contains the source code for my research-notes website, built with [Quarto](https://quarto.org/).

## Scope

- **Derivatives & hedging** — pricing, sensitivities, and hedging methods
- **Stochastic modelling** — processes and models used in quantitative finance
- **Numerical methods** — simulation, approximation, and calibration
- **Quantitative computing** — Python and C++ implementations
